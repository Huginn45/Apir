# Apir Cultural Brand Typography Assets

Drop the custom brand font files into this directory (`assets/fonts/`):
- **Tribo** (`Tribo-Regular.otf` / `Tribo-Regular.ttf`) — Used for main app headers and the `"APIR"` logo wordmark.
- **Garet** (`Garet-Book.otf` / `Garet-Book.ttf`, `Garet-Heavy.otf` / `Garet-Heavy.ttf`) — Default `ThemeData` body and button font family.

Until the `.ttf`/`.otf` files are placed here, the Flutter app automatically falls back to `Montserrat` and `Plus Jakarta Sans`.
